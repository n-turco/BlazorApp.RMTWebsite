# docs

| Folder | Purpose |
|---|---|
| `plans/` | Short written plans created **before** implementing a non-trivial change. One file per task, named `<plan-task-number>-<slug>.md` (e.g. `2.2-home-page.md`). Start from `plans/_template.md`. |
| `decisions/` | Architecture decision records (ADRs): why a significant technical choice was made. Numbered `NNNN-<slug>.md`, never renumbered or deleted — supersede instead. Start from `decisions/_template.md`. |

The overall roadmap is `RMT_Website_Plan.docx` at the repository root. It is a local-only file
(gitignored) — do not commit it.
